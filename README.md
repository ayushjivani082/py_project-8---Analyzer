Project: NumPy Analyzer

Library: NumPy


Concepts: NumPy, Object-Oriented Programming (OOP), arrays, mathematical operations and statistics
Project Objective

The NumPy Analyzer is a menu-driven program that helps users create and manage NumPy arrays. It performs common array operations, mathematical calculations, searching, sorting, filtering and statistical analysis using a DataAnalytics class.
Features


1. Class and Object Structure
Uses a DataAnalytics class to organize the project.
Uses objects and methods to perform operations.
Uses a constructor (__init__) to initialize array data.
2. Array Management

3. 
Create 1D, 2D and 3D NumPy arrays.
Access array elements using indexing.
Select parts of an array using slicing.
Combine arrays using concatenation or stacking.
Split arrays into smaller arrays.
4. Mathematical Operations

5. 
Element-wise addition.
Element-wise subtraction.
Element-wise multiplication.
Element-wise division.
Dot product.
Matrix multiplication for compatible 2D arrays.
6. Search, Sort and Filter

7. 
Search for a specific value in an array.
Sort array elements in ascending or descending order.
Filter elements according to a user-defined condition.
8. Aggregating Functions

9. 
Calculate sum.
Calculate mean (average).
Calculate median.
Calculate standard deviation.
Calculate variance.
10. Statistical Functions

11. 
Find minimum and maximum values.
Calculate percentiles.
Calculate correlation coefficients between arrays.
12. OOP Concepts

13. 
Constructor for initializing data.
Encapsulation using private methods for internal calculations.
Class methods using @classmethod.
Static methods using @staticmethod.
14. User Interface

15. 
Menu-driven interface.
Separate options for array creation, mathematical operations, combining/splitting, searching/sorting/filtering and statistics.
Exit option in the main menu.
Main Menu
The program provides these main options:
Create a NumPy Array
Perform Mathematical Operations
Combine or Split Arrays
Search, Sort or Filter Arrays
Compute Aggregates and Statistics
Exit
Requirements


Python 3
NumPy
Jupyter Notebook or Visual Studio Code
Installation
Install NumPy from the terminal:
pip install numpy
If you are using Jupyter Notebook, you can run this in a notebook cell:
%pip install numpy
How to Run
In Jupyter Notebook
Open the .ipynb notebook in Jupyter Notebook or VS Code.
Run the cells from top to bottom.
Follow the menu displayed in the output.
Enter the option number and provide the requested values.
As a Python File
If the project is saved as a .py file, open the terminal in the project folder and run:
python numpy_analyzer.py
Change the filename in the command if your Python file has a different name.
Example: Creating a 2D Array
import numpy as np

arr = np.array([[10, 20, 30],
                [40, 50, 60]])

print(arr)
Output:
[[10 20 30]
 [40 50 60]]
